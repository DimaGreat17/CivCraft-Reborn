## Coverage counts

- **73/73** wiki navigation entries have a tracked ledger row.
- **19/73** entries have selected effects/requirements explicitly discussed in prior individual-page audit reports. This is **not** full per-item effects validation.
- **54/73** entries are not yet individually audited for runtime effects: index evidence only.
- **2 additional civic centers**: Ратуша and Капитолий are excluded from this navigation subtotal and catalogued with old counterparts in [structure parity](./STRUCTURE_PARITY_27_VS_VIME.md).
- Nation-exclusive articles, 22 world wonders, 6 national wonders, units, portals, artifact effects, special structures are not magically covered by this count; see [wonder matrix](./G0_WONDER_CONSTRUCTION_MATRIX_PASS_11.md) and [nation audit](./VIME_NATIONS_RELIGIONS_WONDERS.md).

## Closure rule

Before a full **behavioral** parity claim can be made, every selected building needs:

`wiki revision + old implementation ref + tech prerequisites + coins/hammers + upkeep + footprint + limits + production inputs/outputs + temporal frequency + upgrades + buffs + owner permissions + war and save/load behavior + AI task/LOD compatibility + exact acceptance tests`.

Absent data must be `UNKNOWN` and impact-assessed, not substituted from old Java or a similarly named building. If GDD explicitly excludes an entry, it can be treated as out-of-scope after recorded user approval; that is not evidence that historical feature did not exist.

## High-impact unmapped categories

- War ships, airship, Tesla tower, fortified walls and military camp: active-combat systems beyond early old Bukkit towers.
- Factory, mine, quarry, granary, sawmill and NPC transport: different item/resource classes and offline production.
- National/exclusive structures: constraints sometimes span all noncaptured cities.
- Roads and walls: old Java custom block paths not in this later standard building list but remain candidate gameplay features.
- Portals, trade ship, oil drilling, sewer, monster farm, pasture, apiary/hive, school/university and modern lab: source effects need separate article pass.
- Event buffs and wonders can change structure stats and become invalid after occupation or city founding.

**Ledger is exhaustive for the 73 indexed titles, but the evidence is NOT exhaustive. G0 remains OPEN.**

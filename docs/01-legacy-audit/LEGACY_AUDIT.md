## Procedure

1. Verify canonical upstream, commit, author and license.
2. Inventory modules, classes, configs, commands, storage, assets and rules.
3. Extract full building, technology and balance catalogs.
4. Classify every original feature as KEEP / ADAPT / REPLACE / EXCLUDE, with reason.
5. Map each feature to GDD, implementation requirements and acceptance tests.
6. Approve a feature parity matrix before implementation.

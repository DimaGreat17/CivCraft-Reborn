# Project Charter

## Core fantasy

Live in a dynamic Minecraft world in which settlements, economies, diplomacy and wars continue independently of the player.

## Player paths

Explorer, craftsperson, trader, citizen, mayor, military commander, ruler. Roles are voluntary and may change.

## Guarantees

- NPC states obey the same systemic material limits as player settlements.
- Civilizations have goals, incentives and strategic constraints.
- Settlements may rise, stagnate, collapse, secede or ally.
- Player-owned terrain is protected by explicit permissions.
- Server-authoritative civilization simulation.

## Open decisions

Loader and game version, NPC scale, building/research catalog, rules of victory, original-source parity, UX, balance, license and migration.

## Gate

No development freeze before edge cases, invariants, data ownership, tests and dependencies are specified and reviewed.

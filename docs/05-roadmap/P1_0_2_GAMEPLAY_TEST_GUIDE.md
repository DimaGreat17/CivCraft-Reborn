# CivCraft Reborn — тест игрового цикла лагеря (сборка 0.2 Development)

**Дата: 2026-11-19. Это разработческая сборка, не релиз 0.2.** Использовать только тестовый мир с резервной копией. Проверка CI-компиляции и загрузки dedicated server не подтверждает корректность интерфейса, AI или 3D-проекций в клиенте.

## 1. Создать и основать лагерь

1. Установить Minecraft Java 26.3 + подходящие Fabric Loader/API + единственный актуальный CivCraft JAR. Убедиться, что включён режим **Мир CivCraft** при создании тестового мира.
2. Создать реальный `Camp Core` по рецепту 3×3: `L I L / S C S / L I L`, где `L` — дубовое бревно (4), `I` — железный слиток (2), `S` — булыжник (2), `C` — костёр (1). Рецепт уже есть в `data/civcraft_reborn/recipe/camp_core.json`.
3. Поставить центр на твёрдую поверхность. Сервер выдаёт **4 обсидиана после КАЖДОЙ установки**. Разместить все 4 по сторонам (N/S/E/W) от центра на одной высоте.
4. Добыть дополнительно **16 дубовых брёвен, 16 булыжника и 8 хлеба** для основания (это предварительный баланс). Рядом с центром нажать **Основать лагерь** или `/civcraft camp found`.
5. Через ПКМ центра открыть управление → **Схема строительства**. До основания был только HEART; после основания должны появиться **только 6 базовых** схем.

## 2. Построить здания самостоятельно

Базовые `STORAGE`, `WORKSHOP`, `FARM`, `BEDROOM`, `SMALL_HOUSE` — **полные многоблочные структуры**, а не «поставить два блока». Проекции строятся из единого с сервером каталога `FunctionalBuildingTemplates.java`.

1. В управлении лагерем открыть схему, выбрать постройку.
2. Сдвинуть/повернуть заготовку на экране размещения; **записать координаты начала пола (origin)**. Постройки допускаются только в рамках радиуса лагеря.
3. Построить все требуемые **физические блоки**. Схема должна скрывать совпавшие блоки; ни один ресурс не появляется бесплатно.
4. Нажать **Принять готовое здание** на экране размещения либо выполнить `/civcraft camp building register STORAGE 0 X Y Z` (заменить тип, поворот и координаты). Если хотя бы один блок отсутствует, сервер не регистрирует здание.
5. `/civcraft camp building list` должен показывать реальное состояние: `WORKING` только пока вся конструкция физически цела, `DAMAGED/UNLOADED` — при повреждении или выгрузке.

## 3. Пригласить и устроить жителей

Первый вариант: существующий рядом vanilla villager + 4 хлеба + свободная проверенная кровать. ПКМ центра → Жители → Принять жителя или `/civcraft camp recruit`.

Второй вариант, если рядом нет деревни: построить реальное жильё, выделить свободную кровать и получить переселенца за **12 хлеба** через `/civcraft camp invite`. Житель — настоящая сохраняемая Minecraft-сущность, а не абстрактное число.

Для назначений подойти к уже зарегистрированному жителю в пределах 8 блоков и открыть раздел **Жители и профессии**:

| Профессия | Требование | Реальное поведение первого рабочего среза |
|---|---|---|
| BUILDER | Нанятый житель и строительный заказ | Идёт к недостающему блоку, берёт реальные материалы из контейнеров и кладёт блоки с задержкой |
| FARMER | Полностью построенная/зарегистрированная FARM | Идёт к созревшей пшенице, собирает реальные дропы; для повторного посева нужна реальная семечка |
| CRAFTSMAN | Полностью построенная WORKSHOP/SMITHY | Переносит настоящие руды и уголь в настоящую печь, обработка — ванильная |
| STOREKEEPER | Полностью построенная STORAGE/GRANARY | Переносит реальные слитки из печи через инвентарь NPC в склад |
| WATCHMAN | SETTLEMENT + WATCHTOWER | Следит за живыми монстрами у башни и предупреждает игроков, не создаёт бесплатную охрану |
| WATER_CARRIER | SETTLEMENT + WELL | Переносит настоящие вёдра воды между физическим источником и складом |

Назначение из GUI посылает **серверную команду**. Требуется целое зарегистрированное здание совместимой профессии, иначе сервер отвергнет назначение.

## 4. Строительство силами NPC

1. Создать полностью физический лагерь и принять жителя.
2. Подойти к нему и выбрать **Назначить строителем** — `/civcraft camp job assign BUILDER`.
3. Положить необходимые *обычные предметы блоков* в реальные сундуки/бочки в пределах 12 блоков от центра лагеря; для грядок нужны земля и мотыга, для воды — ведро воды, для кроватей — кровать.
4. Выбрать схему в каталоге, задать координаты и поворот, нажать **Поручить строительство NPC**, или выполнить `/civcraft camp construction order STORAGE 0 X Y Z`.
5. `/civcraft camp construction list` показывает заказ и прогресс. NPC может работать, только пока загружен вместе с участком; он не должен форсированно загружать чанки и не может бесплатно создавать ресурсы или стирать чужие блоки.
6. Если материалы кончились, заказ **приостанавливается**, не становится завершённым без проверки. После достройки структура автоматически проверяется и регистрируется.

## 5. Повышение до поселения

Текущие проверяемые условия: **3 комнаты, 3 зарегистрированных гражданина, 16 еды в реальном хранилище, исправный зарегистрированный склад, мастерская и ферма**. Проверка `/civcraft camp inspect`, затем `/civcraft camp promote`.

После повышения обновить управление ПКМ центра — открываются продвинутые схемы: `BARRACKS`, `GRANARY`, `SMITHY`, `WATCHTOWER`, `WELL`.

## 6. Обязательные тесты и известные ограничения

- **CRITICAL / client:** ранее выбор схемы `STORAGE` приводил к вылету GPU-render pass. Новый рендер работает через штатный submit collection, но реальная проверка на клиенте **обязательна**.
- **CRITICAL / persistence:** проверить выход/вход, рестарт сервера, задания и физические запасы, отсутствие дублированного жителя, изделия или блока.
- При отсутствии или разрушении части здания, выгрузке чанков, смерти NPC или отсутствии запасов **работа должна остановиться**.
- **Непроверенные части:** сложная система дорог/приоритетов, конкурентные заявки на общие ресурсы нескольких NPC, ремонт и реальная безопасность зданий, полное PHYSICAL/ROOM/CELL, NPC-founded автономные государства и Loaded↔Virtual, масштабные нагрузочные и многопользовательские тесты.
- Поставленные здания сейчас — строго заданные оригинальные структуры; свободные постройки без следования конкретному blueprint для ряда специализаций пока не регистрируются. Расширенные free-form MODULES и архитектурная свобода — следующий этап.
- Баланс ресурсов, рецепты, уровни поселения и NPC-экономика — предварительные и не утверждены как финальные.

**Выпуск 0.2 нельзя объявлять состоявшимся до прохождения клиентских и серверных проверок.**
